插件准备

请先完成以下 QQ 与微信消息源准备，再进入风险确认与环境检测。

QQ 消息源（LiteLoaderQQNT + LLOneBot）

  1. 下载并安装官方 NTQQ，版本需为已验证的 9.9.26-44343。 打开教程 / 下载页
  2. 下载并安装 LiteLoaderQQNT 到 QQNT 版本目录（注入 app_launcher/LiteLoader.js）。 打开教程 / 下载页
  3. 下载 LLOneBot 插件，放入 LiteLoaderQQNT 的 plugins 目录。 打开教程 / 下载页
  4. 启动 QQ 并登录需要接收消息的账号。
  5. 打开 LLOneBot 设置，启用 OneBot v11 正向 WebSocket，端口 3001（默认无 token）。

微信消息源（微信 4.x + wechatauto-replica）

  1. 安装 Python 3.9+（安装时勾选 Add to PATH）。 打开教程 / 下载页
  2. 打开终端执行：pip install wechatauto-replica。 打开教程 / 下载页
  3. 安装或升级官方微信 4.x（推荐 4.1.x），并登录需要接收消息的账号。 打开教程 / 下载页
  4. 保持微信窗口打开，程序将从本地数据库读取消息。

版本与风险提示
  • QQ 已验证版本：9.9.26-44343（其他版本可能导致插件无法运行）。
  • 微信：需官方 4.x（推荐 4.1.x；过低请升级）。
  • 第三方协议插件可能触发账号风控、功能受限或封禁，请自愿承担风险。
!

本程序依赖第三方 QQ 协议插件（LLOneBot + LiteLoaderQQNT）实时读取消息，可能存在账号风控、功能受限或封禁等风险；请确认你已了解并自愿承担相关风险后再继续。

启用微信消息时，本程序会通过 wechatauto-replica 读取微信 4.x 本地消息数据库，同样可能存在账号风控、功能受限或封禁等风险；请谨慎使用并自行承担后果。
